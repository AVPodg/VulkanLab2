# Vulkan Lab 2 — камера и освещение

Лабораторная работа №2 на C++20, Vulkan, GLFW, Dear ImGui и GLM. Объект — пирамида (вариант 6).

Реализованы свободная камера, освещение Блинн–Фонга, фоновый и направленный свет, добавление и удаление точечных источников и прожекторов. Для точек и прожекторов используются storage buffers и затухание по закону обратных квадратов; у прожекторов настраиваются внутренний и внешний углы мягкого края. Данные сцены и модели разделены на два набора дескрипторов. Нормали граней генерируются процедурно.

Источники обозначены цветными кубами, направления и углы прожекторов — белыми линиями. Обозначения можно скрывать, их цвет не зависит от освещения. В интерфейсе доступны материал, преобразования и анимация пирамиды. Сохранён режим первой лабораторной; переключение — **F1**.

## Сборка и запуск

Для Windows нужны видеодрайвер с Vulkan 1.1+, Visual Studio 2022 с компонентом разработки на C++, CMake 3.24+, Git и Vulkan SDK с компилятором `glslc`. При первой сборке библиотеки скачиваются через CMake.

В PowerShell из папки проекта:

```powershell
cmake --preset msvc-release
cmake --build --preset msvc-release --parallel 4
.\build-msvc\bin\Release\camera-lighting-lab.exe
```

В исходном рабочем каталоге `D:\kg lab\lab2`, где рядом сохранены инструменты и зависимости `lab1`, доступна сборка через GCC/MSYS2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build-local\bin\camera-lighting-lab.exe
```

Перед пересборкой закройте программу. После изменения C++ или GLSL повторите сборку и запуск. Шейдеры компилируются и копируются автоматически. Для переноса готовой сборки сохраняйте папку `shaders` и DLL рядом с `.exe`.

## Управление

- **W/A/S/D** — движение камеры, **Q/E** — вниз/вверх, левый **Shift** — ускорение.
- Правая кнопка мыши с перемещением над сценой — поворот взгляда.
- Колесо над сценой — угол обзора или размер ортографической области; над панелью — прокрутка панели.
- **Space** — пауза анимации пирамиды, **R** — сброс, **F1** — переключение лабораторных, **Esc** — выход.
- Разделы панели раскрываются нажатием на заголовок. Настройки камеры, материала и источников применяются сразу.
- `Add point light` / `Add spotlight` добавляют источник; внутри его раздела доступны параметры и кнопка удаления.
- `Reset scene` возвращает начальные настройки. `Base task: directional light only` оставляет только фоновый и направленный свет.
- `Light cubes` и `Spot cones + directions` управляют обозначениями, не отключая освещение.

## Исходники

- `source/lighting_scene.*` — настройки, камера, геометрия и процедурные нормали.
- `source/lab2_application.*` — интерфейс, управление и переключение режимов.
- `source/lighting_renderer.*` — Vulkan-буферы, дескрипторы и отрисовка.
- `shaders/lighting.*` — преобразования и расчёт освещения.
- `shaders/marker.*` — обозначения источников постоянным цветом.
- `source/application.*`, `source/scene.hpp`, `shaders/pyramid.*` — сохранённая первая лабораторная.
- `source/graphics_internal.*` — служебный Vulkan-каркас на основе [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app/tree/master/source) с исправлениями инициализации, пула ImGui, синхронизации и проверки результата показа кадра.

Лицензия исходного каркаса сохранена в `LICENSE` и `NOTICE`. Готовая сборка, инструменты, зависимости и временные файлы исключены через `.gitignore`.
